# Pawlished CRM

## Local development

1. Install dependencies:
   - `npm install`
2. Create `.env.local` from `.env.example`.
3. Run:
   - `npm run dev`

## Build

- `npm run build`

## Vercel + Supabase control

Operational commands are documented in `OPERATIONS.md`.

Quick check:

- `npm run ops:status`
